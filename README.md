# Тайное голосование Учёного совета ИШИТР — фронтенд

Чистые HTML, CSS и JavaScript (ES-модули), без сборки, фреймворков и CDN.
Шрифт Jost лежит локально, поэтому всё работает в сети кабинета без интернета (NFR-02).
Стили собраны по UI-kit «TPU Solutions»: цвета, отступы, скругления и тени.

## Запуск за минуту

```bash
cd golos-frontend
python3 -m http.server 8080
```

Откройте `http://localhost:8080/login.html`.

- Вход секретаря: `secretary / secretary`.
- Вход администратора: `admin / admin`.
- Экран для проектора: `http://localhost:8080/screen.html`. Удобно держать его в соседней вкладке.

> Двойной клик по `.html` не подойдёт: браузер не загружает ES-модули с `file://`. Нужен любой локальный сервер.

### Демо-режим

Пока бэкенд не готов, все запросы обрабатывает `js/mock.js` — демо-сервер прямо в браузере. Он повторяет контракт API из раздела 11 ТЗ:

- таймеры пунктов и автоматическую смену кандидатур в пакете;
- 15 эмулированных пультов, которые голосуют в течение пункта;
- иногда один член совета не голосует — так видно недействительный пункт и повтор;
- остановку голосования, историю, выгрузку и реестр пультов.

Данные хранятся в `localStorage`, поэтому пульт управления и экран в разных вкладках видят одно состояние.

Полезные адреса:

- `?reset=1` на любой странице — сбросить демо-данные к начальным.
- `?mock=0` — работать с настоящим сервером, `?mock=1` — вернуться в демо. Выбор запоминается.
- Постоянное значение по умолчанию задаётся в `js/config.js` → `DEFAULT_MOCK`.

## Подключение к FastAPI

Самый простой способ — FastAPI раздаёт папку целиком:

```python
from fastapi.staticfiles import StaticFiles
from fastapi.responses import RedirectResponse

app.mount("/static", StaticFiles(directory="golos-frontend"), name="static")

@app.get("/admin")
def admin(): return RedirectResponse("/static/meetings.html")

@app.get("/screen")
def screen(): return RedirectResponse("/static/screen.html")
```

Чтобы отдавать страницы по красивым путям из ТЗ (`/admin/history` и т. п.), положите HTML в корень раздачи: все ссылки внутри относительные.

Киоск на Raspberry Pi:

```
chromium-browser --kiosk --noerrdialogs --incognito http://localhost:8000/static/screen.html
```

## Контракт API

Всё по разделу 11 ТЗ. Ошибки — в формате FastAPI `{ "detail": "текст для человека" }`: фронтенд показывает `detail` как есть, поэтому пишите его по-русски.

**Из ТЗ:**

- `POST /api/auth/login`
- `GET /api/meetings`, `POST /api/meetings`, `PATCH /api/meetings/{id}` — поля `present_count`, `status`, `title`, `held_on`
- `POST /api/meetings/{id}/votes` — тело `{kind, title, item_seconds, status: "draft"|"ready", items: [{text} | {candidate_name, candidate_post}]}`
- `PUT /api/votes/{id}`, `DELETE /api/votes/{id}`
- `POST /api/votes/{id}/start`, `/stop`, `/repeat`
- `GET /api/votes/{id}/progress` → `{status, current_position, total_items, received, present, seconds_left, item_seconds, is_repeat, item: {...}}` — без разбивки по вариантам
- `GET /api/history?from=&to=`
- `GET /api/export.xlsx?meeting_id=` или `?from=&to=`
- `GET /api/devices`, `POST /api/devices`, `PATCH /api/devices/{id}`
- `GET /api/screen/state`

**Добавлено для интерфейса, нужно реализовать на бэкенде:**

| Метод и путь | Зачем |
|---|---|
| `GET /api/auth/me` → `{id, login, name, role}` | Шапка и проверка сессии; без входа — 401 |
| `POST /api/auth/logout` | Кнопка «Выйти» |
| `GET /api/meetings/{id}` | Заседание с голосованиями, пунктами и закрытыми попытками. Пока голосование `running`, `attempts` пустые |
| `PUT /api/meetings/{id}/votes/order` `{vote_ids:[…]}` | Порядок голосований |
| `POST /api/meetings/{id}/show-agenda` | Кнопка «Показать повестку» |
| `POST /api/votes/{id}/show-results` | «Итоги на экран» |
| `POST /api/votes/{id}/paper` | Пометить недействительные и непроведённые пункты статусом `paper` |
| `POST /api/devices/{id}/identify` | Мигнуть светодиодами пульта |
| `GET/POST /api/admin/backup` | Время последней копии и копия по команде (NFR-09) |

Права: `GET /api/devices` нужен и секретарю (сетка пультов в пульте управления), изменения — только администратору.

Поля голосования, которые читает фронтенд:

- `items_count`
- `invalid_count` (`null`, пока идёт голосование)
- `problems` — список строк вроде «без должности: 1» у черновиков

Состояния экрана (`/api/screen/state`):

| `mode` | Поля |
|---|---|
| `idle` | — |
| `agenda` | `votes` |
| `voting` | `vote`, `item`, `seconds_left`, `item_seconds`, `present` — без счётчиков |
| `results` / `stopped` | `vote`, `items[].attempt` |

## Что важно для анонимности (NFR-01)

- Интерфейс не получает и не показывает разбивку голосов открытого пункта: ни на экране, ни секретарю.
- Неполный счёт остановленной попытки не показывается — вместо цифр «—».
- Номер пульта нигде не связан с человеком; в журнале действий демо-сервера нет выбора.
- В демо-сервере «нажатия» пультов удаляются при закрытии пункта — так же, как `ballot_receipt` в схеме ТЗ.

## Доступность и браузеры

- Chrome, Firefox, Яндекс Браузер последних версий (NFR-07).
- Нужны `<dialog>` и `:has()` — есть в Firefox с версии 121.
- Работа с клавиатуры: видимый фокус, сортировка стрелками, диалоги закрываются по Esc.
- Подписи у полей, `aria-live` для статуса и уведомлений, уважение к `prefers-reduced-motion`.
- Страницы панели работают на ширине телефона.
